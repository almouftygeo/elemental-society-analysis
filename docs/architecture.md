# MALEG Ingestion Architecture

```text
┌─────────────────────────────────────────────────────────────┐
│                    SOURCE-SPECIFIC DATA                      │
├─────────────────────────────────────────────────────────────┤
│ Sensors (T,P,flow,pH,EC)  Labs (ICP-MS,IC,GC)  Events       │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                  SOURCE-SPECIFIC ADAPTERS                    │
├─────────────────────────────────────────────────────────────┤
│ SensorAdapter      LabCSVAdapter      EventAdapter           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                   CANONICAL DATA MODEL                       │
├─────────────────────────────────────────────────────────────┤
│ SensorRecord · LabResult · OperationalEvent                  │
│ (frozen, UTC timestamps, censoring preserved)                │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    QUALITY VALIDATION                        │
├─────────────────────────────────────────────────────────────┤
│ VALID / SUSPECT / REJECTED (+ reason)                        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│              IMMUTABLE RAW STORAGE (SQLite)                  │
├─────────────────────────────────────────────────────────────┤
│ raw_sensor_payload · raw_lab_payload · raw_event_payload     │
│ (append-only, no UPDATE/DELETE)                              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│               TIME-AWARE INTEGRATION                         │
├─────────────────────────────────────────────────────────────┤
│ merge_asof (backward) · freshness · rolling (shift-first)    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                ML-READY FEATURE TABLE                        │
└─────────────────────────────────────────────────────────────┘
```
