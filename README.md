## 📋 Overview

Elemental Society Analysis is a professional geochemical data cleaning and exploratory data analysis (EDA) suite designed for exploration geologists, mining professionals, and geochemists. It transforms raw geochemical data into actionable insights with a user-friendly interface.

**Developed by:** Mohamed Almoufty Abdoalmoutleb Abaker

## 🔧 Features

### Data Management
- Upload CSV and Excel files with auto-detection of delimiters
- Clean data (handle missing values, detection limits, outliers)
- Rename files and delete selected rows/columns
- Data quality summary dashboard

### Statistical Analysis
- Basic statistics (mean, median, std dev, skewness, kurtosis)
- Variance analysis
- Correlation matrix (Pearson, Spearman, Kendall)
- IQR outlier detection

### Visualization
- Correlation heatmap with strongest correlations highlighted

# 🧪 Elemental Society Analysis

**Professional Geochemical Data Analysis Suite**
- PCA scores with PC1 direction and loadings
- Scatter plots with trend lines
- Outlier visualization
- Threshold analysis
- Distributions (Histogram, PDF, CDF, Box Plot)
- Combined views

### Exploration Geochemistry
- Alteration Indices (Ishikawa AI, CCPI, Sericite Index)
- Element Ratios (Au/Cu, Zn/Pb, Cu/Zn, etc.)
- Mineralization Indices (Gold Index, Base Metal Index)
- Grade Statistics with classification (HIGH/MEDIUM/LOW)

### Export
- CSV (semicolon or comma separated)
- Excel (.xlsx)
- JSON
- Professional HTML Reports
